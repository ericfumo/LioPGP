# LioPGP Material Design 3 設計系統 / Material Design 3 设计系统

## 概述 / 概述

LioPGP 實現 Material Design 3（Material You）與密碼學證書管理的客製化主題。設計系統強調清晰度、安全提示和可訪問性。

LioPGP 實現 Material Design 3（Material You）與密碼學證書管理的客製化主題。設計系統強調清晰度、安全提示和可訪問性。

## 設計原則 / 设计原则

1. **安全優先的清晰度** - 視覺層級優先考慮安全關鍵信息
2. **通過透明性建立信任** - 證書狀態和金鑰信息始終可見
3. **可訪問性** - 最少符合 WCAG 2.1 AA 標準
4. **效能** - 在中端設備上保持 60fps+ 的流暢動畫
5. **適應性** - 響應式佈局支持手機、平板和可摺疊設備

### 演算法徽章樣式 / 演算法徽章样式

徽章使用語義顏色指示金鑰演算法：
- **RSA**: 藍色 - 傳統非對稱密碼
- **ECC**: 紫色 - 橢圓曲線密碼
- **PQC**: 綠色 - 後量子安全
